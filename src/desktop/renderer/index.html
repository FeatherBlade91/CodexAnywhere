实例配置：支持 OpenAI 的应用

先登录并启动服务。在应用中新增 OpenAI 兼容提供商：Base URL 填上方 API 地址（包含 /v1），API Key 填上方本地密钥。不要填写 ChatGPT 密码。

模型 ID 可通过 GET /v1/models 查询。比如 gpt-6.1-sol 就请求同名实际模型；应用显示名称可自定义，但请求的 model 不会替换成主页的 Claude Code 模型，也不会解析别名或 [1M] 后缀。

effort 如何对应思考强度

Chat Completions 使用 reasoning_effort，代理将其原样转换为 Responses 的 reasoning.effort。直接使用 Responses 时填写 reasoning={"effort": "high"}。不要使用顶层 effort。

low → low（低）medium → medium（中）high → high（高）xhigh → xhigh（超高）max → max（最高）

这些值不互相降级或重命名，具体支持范围取决于模型与账号；不传时由上游选择默认强度。这五档是本应用模型目录展示的范围，OpenAI 端点将其他值也原样交给上游验证。Claude Code 的 output_config.effort 则在本地校验这五档，未填写时优先 high，否则使用模型支持列表的第一项。
