ChatGPT Plan Bridge

1. 安装向导选择 CC Switch 管理（推荐）或 Claude Code 直连。
2. 打开“ChatGPT Plan Bridge 管理器”，点击“登录 / 重新授权”。
3. 浏览器中允许应用使用 ChatGPT 订阅额度。无需 OpenAI API Key。
4. 返回管理器，点击“刷新模型与状态”。模型来自当前账号的可用列表。
5. CC Switch 模式：刷新/重启 CC Switch，在 Claude Code 页面启用“ChatGPT 订阅”，切到“聚合”模式。
   这里只有一个供应商，全部模型在 Claude Code 的 /model 列表内切换。
   直连模式：所选默认模型直接写入 Claude Code 配置。已有连接配置会被覆盖，其他设置保留，覆盖前自动备份。
6. 新开终端运行 claude。

模型带 [1M] 客户端标记。这并不扩大服务端限制：测试账号目录默认窗口为 500K/272K、最大值为 872K；未执行百万 token 测试。

思考强度：
  在 Claude Code 会话中输入 /effort low、/effort medium、/effort high、/effort xhigh 或 /effort max。
  也可以启动时运行 claude --effort xhigh。
  桥接会把受支持档位原样传给模型的 reasoning.effort；不支持的档位明确报错，不会偷偷降档。
  如果客户端未发送 effort，桥接默认 high。ultracode 是 Claude Code 的工作流开关，不是额外的 GPT effort 档。

网络：首次自动读取 Windows 系统代理。网络不通时，在管理器修改代理（例如 http://127.0.0.1:7897），保存并重启。
日志与凭据：%LOCALAPPDATA%\ChatGPTClaudeBridge。OAuth 凭据使用当前 Windows 用户的 DPAPI 加密。
OAuth 失效时重新登录。额度及应用授权在 https://chatgpt.com/settings/usage 管理。
模型数量、可用能力、额度由账号与 OpenAI 决定。此软件不提供额外额度、不绕过模型权限。

软件仅监听本机 127.0.0.1，自动刷新 OAuth token，不使用 Codex CLI 或 backend-api。
安装包自带 Node.js，不需要手动安装 Node.js/Python。Claude Code 本身仍需自行安装。
支持 Windows 10/11 与相应 Windows Server；提供 x64、ARM64、x86 桥接运行时。
Claude Code 和 CC Switch 自身的系统/架构限制仍适用。没有实测的架构会在测试报告中明确标注。

卸载：Windows“已安装的应用”中卸载；可选择恢复此工具管理的连接配置。个人凭据和备份默认保留以便重装。
发布包未购买代码签名证书，Windows 可能显示未知发布者。请核对私有仓库发布页的 SHA256。

本软件为独立第三方工具。内置 OpenAI SIWC DevKit 受其非商业许可证约束；许可证随安装包提供。
